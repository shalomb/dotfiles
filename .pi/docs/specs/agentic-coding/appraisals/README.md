# Appraisals and intent notes

Advisory documents about the goal system. None of them changes code, specs or ADRs.
Written 2026-11-02 as input for later design rounds.

| Document | Type | What it covers |
|---|---|---|
| `goal-system-intent-layers-appraisal.md` | Appraisal | The goal system against a layered model of intent, with nine points to consider |
| `discovery-to-delivery-intent.md` | Intent | Connecting discovery and product ownership to `/goal` |
| `control-and-execution-plane-intent.md` | Intent | Separating flow management from execution, and choosing topologies |
| `skill-systematization-intent.md` | Intent | Giving the skills structure with higher-order skills |
| `role-to-skill-mapping-draft.md` | Mapping | Roles in the spec against existing and candidate skills |
| `open-decisions.md` | Decision log | Every open question from the documents above, in one place |

## Reading order

1. The appraisal, for the current state and its gaps.
2. The three intent notes, in any order.
3. The mapping, then the decision log.

## Limits

- Statements come from reading specs and skill descriptions. No tests were run.
- External input is one video transcript and one practitioner's view.
- The decision log lists questions. It records no answers.
