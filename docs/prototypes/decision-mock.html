The three ways forward

Option 1

Let it lapse

  • No cost, no owner needed
  • If something does use it, that thing breaks on 10 Dec
Safe only if usage evidence is clean.
Recommended

Ask the owner, then delete

  • Costs one question and a few days
  • Leaves a record against the incident
  • Needs someone to answer before 6 Dec
If no one answers by 6 Dec, treat it as option 1.
Option 3

Renew now

  • No surprise outage
  • Pays for something nobody owns
  • Needs a repo and workspace we have not found
Only if an owner confirms a planned use.

Why this one

Deleting something unowned is cheap to undo (a new certificate takes minutes), while renewing it quietly adds a cost that nobody tracks. The only real risk is a hidden user, and one question to the account's owner closes that.
